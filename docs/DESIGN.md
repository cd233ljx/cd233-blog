# 设计与阅读

本站以 [Anthony Fu 的个人网站](https://antfu.me/)为主要视觉参考：白色背景、窄幅单列、无衬线字体和轻量导航。结合 Josh W. Comeau 的局部趣味与 Manu 的自然写作气质，保留本站的中文内容和标签蓄水池。

## 视觉约定

- 首页从作者名字和正常长度的介绍开始，保留「cd233的个人博客~」作为小字。首页介绍使用作者提供的四段文字，不再追加文章推荐链接。置顶文章优先排列在最近文章列表中。
- 作者介绍以已有事实为依据。新的经历、头像和社交链接由作者提供，不照搬参考站作者的身份和作品。
- 首页、文章列表、归档、关于和正文共用 `41rem` 的内容宽度。大屏留白与小屏的 `1.75rem` 外边距共同形成阅读节奏。
- 主标题约 `36px`，文章列表标题约 `18px`，正文 `16px`。中文正文行高 `1.9`，使用实际页面检查断行与密度。
- 英文使用自托管 Inter 的 Latin 可变字体；中文使用系统无衬线字体。正文引用使用已有的 Noto Serif SC，为写作保留一点不同的语气。
- 文章列表使用日期、标题、简短摘要、阅读时间和少量标签，统一由 `PostList.astro` 渲染。链接分别可点击，不使用覆盖整个条目的隐藏链接。
- 导航保持轻量，链接与搜索、主题切换共用已有的 Lucide 线性图标。手机菜单有明确的展开、关闭和焦点状态。
- 页面跳转使用清晰的文字链接，不附加箭头字符或箭头图标；前台和后台保持一致。
- 首页标签蓄水池是作者明确喜欢的特色，由 `TagPool.astro` 独立维护。保留水位变化、标签浮动与悬停上浮，不把它当作模板装饰删除。键盘聚焦同样展开标签；手机直接排列，系统减弱动效设置关闭浮动。
- 正文目录在宽桌面位于右侧，在较窄视口放在正文前。目录不能因切到手机而消失。
- 宽屏两侧使用作者选择的 [Antfu「Plum」枝条生长](https://100.antfu.me/013)作为背景参考。两簇灰绿色细枝从左右边缘向内生长，完成后静止，保留大片空白；限制分叉数量，避开正文和目录，接近内容时渐淡。宽度小于 `1100px` 时隐藏，系统减弱动效时直接显示完整静态枝条。颜色和强度分别由 `--ambient-ink`、`--ambient-opacity` 控制。
- 背景不响应鼠标、不可点击、不可聚焦。主题切换沿用同一枝条形状，仅重新绘制颜色。标签池保留自己的动效。文章和标题直接可见，滚动交给浏览器，阅读不等待枝条生长。
- 浅色以白色、深灰为主，绿色用于交互与水池；深色使用同一套语义 token。普通文字的对比度以至少 `4.5:1` 为目标。
- 移动端、深色主题、键盘焦点、菜单关闭状态和富内容组件都属于设计验收范围。

## 修改方式

在现有组件与样式模块中调整，在 `theme.css` 原位维护配色和标签池效果，保留 `global.css` 的导入顺序。替换对应旧规则，避免追加另一套全站覆盖。

共享站点身份维护在 `src/config/site.ts`。文章来自内容集合，日期、数量和标签从实际内容计算。

## 系列视图

主导航增加「系列」，与按日期排列的文章、归档并存。系列列表沿用窄幅单列和轻分隔线；详情按章节顺序排列，文章页提供所属系列与前后篇链接。标签继续用于交叉检索。

系列页面面向读者，只保留标题、篇目、数量和必要导航。开发环境可以显示草稿标记；写作说明、终端命令和源码路径只放在仓库文档中，不展示在阅读页面。正式页面只呈现公开篇目。

算法系列的交互卡片沿用正文宽度与绿色强调色，以标题、输入、播放控制、状态区、说明和伪代码形成阅读顺序。当前状态不只靠颜色区分，表格提供文字图例；大表只在卡片内部横向滚动。图表提供刻度与数值替代内容，操作按钮保持文字标签，播放不自动开始。

## 写作后台

后台文章工作区采用类似 Obsidian 的 Markdown 编辑与阅读预览，使用独立的侧栏导航与工作区。文章列表、媒体库、页面与站点、发布中心分开；点击文章进入完整写作页，不再把文章列表和长表单挤在正文旁边。不添加主站入口。

后台左侧导航可通过顶部按钮收为 64px 图标栏，保留导航、主题与退出入口及可访问名称。未手动选择时，文章编辑页和较窄桌面默认收起；手动展开或收起后在本机记住选择。手机继续使用底部导航，不额外占用正文宽度。右侧文章设置默认关闭，按需展开。

标题和正文占据中央主要空间，摘要、标签、日期、封面和固定地址放入可收起的右侧设置栏。顶部固定显示保存、预览与发布。文章正文支持编辑、分栏和阅读视图，分栏默认并排显示 Markdown 与单篇实时预览；窄屏上下排列。动画和组件可在阅读窗直接操作，不显示组件属性表单或源码占位卡片。放大预览对话框支持桌面和手机尺寸。

保存与上线是不同状态。自动保存用于继续写作，发布确认列出所有即将生效的内容。恢复历史只影响编辑稿，失败构建保留线上版本。媒体库提供缩略图、搜索、描述与复用。页面内容按实际页面分组，不要求作者手写 JSON。

浅色、深色均使用现有主题语义颜色。CodeMirror 和可视化编辑器的正文、菜单、卡片及表格共用可读的文字颜色。移动端导航置底，文章设置作为可关闭侧栏；键盘弹窗使用原生 dialog 管理焦点与 Escape。主题切换、查看博客与退出入口在手机端同样可达。

参考：[Ghost 写作编辑器](https://ghost.org/help/using-the-editor/)、[MDXEditor](https://mdxeditor.dev/editor/docs/getting-started)。

后台「系列」使用左侧系列列表、右侧篇目目录的主从布局；窄屏将系列选择放在目录上方。系列资料移入独立对话框，让篇目和阅读顺序成为主要内容。文章选择器支持搜索、多选和归属筛选，跨系列移入时显示原归属。目录提供拖动手柄、Alt + 上下方向键和位置选择，移出操作可撤销。底部常驻保存状态及调整摘要，保存失败保留现场；进入正文前先保存，返回后保留选中的系列。后台品牌区域仅保留站点名称和「写作空间」，不再显示字母 C 徽标。

交互参考 [Notion 的侧栏组织](https://www.notion.com/help/navigate-with-the-sidebar)与 [GitBook 的篇目管理](https://gitbook.com/docs/create-content/content-structure/page)：固定的内容导航、直接排序、按需展开的资料及操作。本站保持单层系列与现有配色，不引入多层页面结构。

阅读窗中的公式按实际数学排版显示，交互组件直接运行；仓库修改同步到浏览器。相关编辑说明不出现在读者页面。

文章正文采用客户端即时预览，预览不要求先保存或填写标题。分栏和放大预览使用同一套正文样式。MDX 交互演示集中显示在已同步演示区，保留操作状态，普通文字输入不重载组件。状态文案区分本地预览与后台同步，不把网络失败显示成正文无法阅读。
