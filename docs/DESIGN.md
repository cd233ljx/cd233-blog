# 设计与阅读

本站以 [Anthony Fu 的个人网站](https://antfu.me/)为主要视觉参考：白色背景、窄幅单列、无衬线字体和轻量导航。结合 Josh W. Comeau 的局部趣味与 Manu 的自然写作气质，保留本站的中文内容和标签蓄水池。

## 视觉约定

- 首页从作者名字和正常长度的介绍开始，保留「cd233的个人博客~」作为小字。置顶文章放在介绍中的链接里，最近文章包含它，避免只有一篇文章时出现空列表。
- 作者介绍以已有事实为依据。新的经历、头像和社交链接由作者提供，不照搬参考站作者的身份和作品。
- 首页、文章列表、归档、关于和正文共用 `41rem` 的内容宽度。大屏留白与小屏的 `1.75rem` 外边距共同形成阅读节奏。
- 主标题约 `36px`，文章列表标题约 `18px`，正文 `16px`。中文正文行高 `1.9`，使用实际页面检查断行与密度。
- 英文使用自托管 Inter 的 Latin 可变字体；中文使用系统无衬线字体。正文引用使用已有的 Noto Serif SC，为写作保留一点不同的语气。
- 文章列表使用日期、标题、简短摘要、阅读时间和少量标签，统一由 `PostList.astro` 渲染。链接分别可点击，不使用覆盖整个条目的隐藏链接。
- 导航保持轻量，链接与搜索、主题切换共用已有的 Lucide 线性图标。手机菜单有明确的展开、关闭和焦点状态。
- 首页标签蓄水池是作者明确喜欢的特色，由 `TagPool.astro` 独立维护。保留水位变化、标签浮动与悬停上浮，不把它当作模板装饰删除。键盘聚焦同样展开标签；手机直接排列，系统减弱动效设置关闭浮动。
- 正文目录在宽桌面位于右侧，在较窄视口放在正文前。目录不能因切到手机而消失。
- 宽屏两侧使用作者选择的 [Antfu「Plum」枝条生长](https://100.antfu.me/013)作为背景参考。两簇灰绿色细枝从左右边缘向内生长，完成后静止，保留大片空白；限制分叉数量，避开正文和目录，接近内容时渐淡。宽度小于 `1100px` 时隐藏，系统减弱动效时直接显示完整静态枝条。颜色和强度分别由 `--ambient-ink`、`--ambient-opacity` 控制。
- 背景不响应鼠标、不可点击、不可聚焦。主题切换沿用同一枝条形状，仅重新绘制颜色。标签池保留自己的动效。文章和标题直接可见，滚动交给浏览器，阅读不等待枝条生长。
- 浅色以白色、深灰为主，绿色用于交互与水池；深色使用同一套语义 token。普通文字的对比度以至少 `4.5:1` 为目标。
- 移动端、深色主题、键盘焦点、菜单关闭状态和富内容组件都属于设计验收范围。

## 修改方式

在现有组件与样式模块中调整，在 `theme.css` 原位维护配色和标签池效果，保留 `global.css` 的导入顺序。替换对应旧规则，避免追加另一套全站覆盖。

共享站点身份维护在 `src/config/site.ts`。文章来自内容集合，日期、数量和标签从实际内容计算。

## 参考与应用

| 参考                                                                                 | 在本站的应用                                                                                          |
| ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| [Anthony Fu](https://antfu.me/)                                                      | 主要参考：约 656px 的内容宽度、Inter、36px 开场标题、轻导航与自然段落。借鉴首页和中文文章的阅读尺度。 |
| [Josh W. Comeau](https://www.joshwcomeau.com/)                                       | 趣味集中在局部交互；本站用已有标签池承载这种个性。                                                    |

| [Fontsource Inter](https://fontsource.org/fonts/inter)                               | 从直接依赖引用字体文件，只打包 Latin 的正体和斜体，保留 OFL 许可。                                    |
| [W3C：文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) | 浅色、深色与辅助文字分别检查，不用极淡的文字模拟参考站的淡入过程。                                    |
| [Astro：Styles and CSS](https://docs.astro.build/en/guides/styling/)                 | 保持共享样式的层叠顺序与职责可预测。                                                                  |

这是对选定方向的适配。本站保留自己的站点名、文章、搜索和标签池，不复制参考站的个人标识与社交链接。

背景运动改编自 [Antfu 的 Plum 源码](https://github.com/antfu/100/blob/main/src/pages/013.vue)，使用原生 Canvas 2D，沿用逐代生长、随机转向与概率分叉的做法，不引入图形框架。原参考的黑白方形画布适配为两侧透明灰绿色枝条；后期降低分叉概率并限制线段总量，让枝条自然收束。源代码的 MIT 版权与许可保留在 `public/licenses/antfu-100-MIT.txt` 中，随静态站点一起发布。
