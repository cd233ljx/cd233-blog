## 一、算法的基本概念

### 1.1 算法与程序

**算法**：解决某个可计算问题的有限步骤序列。

**程序**：使用程序设计语言实现某个计算过程。

二者的主要区别：

- 算法必须满足有限性，即经过有限步骤终止。
- 程序不一定终止，例如操作系统中的常驻服务。
- 算法强调解决问题的方法，程序强调方法的具体实现。

### 1.2 算法的四个基本性质

| 性质   | 含义                                           |
| ------ | ---------------------------------------------- |
| 输入   | 零个或多个输入                                 |
| 输出   | 至少产生一个输出                               |
| 确定性 | 每条指令含义明确、无歧义                       |
| 有限性 | 经过有限步骤终止，每步操作也应在有限时间内完成 |

注意：

1. 算法可以没有输入，但不能没有输出。
2. 程序可以不满足有限性。
3. 部分教材还会增加“可行性”作为第五个性质。

### 1.3 问题的分类与一般化

课件涉及：

- 可计算问题与不可计算问题。
- 离散数据问题与连续数据问题。
- 离线问题与在线问题。

算法设计强调问题的一般化。

例如：

固定问题：

```text
计算 1 + 2 + ... + 100
```

一般化问题：

```text
输入正整数 n，计算 1 + 2 + ... + n
```

其中 `n` 是问题规模。

补充：课件将网页设计作为“不可计算问题”的示例，更准确地说，这是目标开放、难以定义唯一标准解的设计任务，并非计算理论中严格意义上的不可计算问题。

### 1.4 算法设计的价值

同一个问题通常有多种算法。

例如求自然数之和：

方法一：循环累加。

```python
s = 0
for i in range(1, n + 1):
    s += i
```

时间复杂度：`O(n)`。

方法二：直接使用数学公式。

```python
s = n * (n + 1) // 2
```

在通常的基本运算时间模型下，时间复杂度：`O(1)`。

**结论：算法设计的核心目标之一，是寻找时间或空间开销更低的求解方法。**

## 二、算法复杂度分析

### 2.1 时间复杂度与空间复杂度

**时间复杂度**：衡量算法执行操作次数随问题规模增长的趋势。

**空间复杂度**：衡量算法运行过程中所需存储空间随问题规模增长的趋势。

通常用：

- `T(n)` 表示时间复杂性函数。
- `S(n)` 表示空间复杂性函数。

严格而言，复杂度可能同时受到问题规模、具体输入和算法本身影响。

### 2.2 三种时间复杂度

| 类型     | 含义                             |
| -------- | -------------------------------- |
| 最好情况 | 最有利输入下的运行时间           |
| 最坏情况 | 最不利输入下的运行时间           |
| 平均情况 | 根据输入概率分布计算期望运行时间 |

一般重点分析最坏时间复杂度。

例如顺序查找：

```python
for i in range(n):
    if a[i] == target:
        return i
```

- 最好情况：第一个元素就找到，`Θ(1)`。
- 最坏情况：最后一个元素找到或不存在，`Θ(n)`。
- 平均情况：若目标等概率地出现在各位置，则为 `Θ(n)`。

**注意：时间复杂度不一定只取决于问题规模，还可能取决于输入数据。**

### 2.3 常见时间复杂度

从增长慢到增长快：

$$
O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(2^n)<O(n!)
$$

常见对应关系：

| 复杂度     | 典型算法           |
| ---------- | ------------------ |
| O(1)       | 数组下标访问       |
| O(log n)   | 二分查找           |
| O(n)       | 数组遍历           |
| O(n log n) | 归并排序           |
| O(n²)      | 选择排序、冒泡排序 |
| O(2ⁿ)      | 枚举所有子集       |
| O(n!)      | 枚举所有排列       |

### 2.4 循环复杂度的计算

**情况一：单层循环**

```python
for i in range(n):
    pass
```

执行 `n` 次：

$$
T(n)=\Theta(n)
$$

**情况二：双层循环**

```python
for i in range(n):
    for j in range(n):
        pass
```

执行 `n²` 次：

$$
T(n)=\Theta(n^2)
$$

**情况三：内层循环与外层有关**

```python
for i in range(n):
    for j in range(i):
        pass
```

执行次数：

$$
T(n)=0+1+2+\cdots+(n-1)
$$

$$
=\frac{n(n-1)}2
$$

因此：

$$
T(n)=\Theta(n^2)
$$

**情况四：每次规模减半**

```python
while n > 1:
    n //= 2
```

执行次数满足：

$$
\frac{n}{2^k}\le1
$$

因此：

$$
k=\Theta(\log_2 n)
$$

所以时间复杂度：

$$
T(n)=\Theta(\log n)
$$

### 2.5 复杂度计算规则

1. 顺序结构：复杂度相加，保留最高阶。
2. 嵌套循环：计算总执行次数，不一定直接相乘。
3. 分支结构：最坏情况通常取较大分支。
4. 规模不断减半：通常出现对数复杂度。
5. 忽略常数因子和低阶项。

例如：

$$
T(n)=3n^2+4n\log n+7
$$

最高阶为 `n²`：

$$
\boxed{T(n)=\Theta(n^2)}
$$

## 三、渐近复杂度符号

### 3.1 五种渐近符号

| 符号    | 含义         | 直观理解                         |
| ------- | ------------ | -------------------------------- |
| O(g(n)) | 渐近上界     | 不会比 g(n) 增长得更快一个数量级 |
| Ω(g(n)) | 渐近下界     | 不会比 g(n) 增长得更慢一个数量级 |
| Θ(g(n)) | 渐近紧确界   | 与 g(n) 同阶                     |
| o(g(n)) | 严格渐近上界 | 增长速度严格慢于 g(n)            |
| ω(g(n)) | 严格渐近下界 | 增长速度严格快于 g(n)            |

### 3.2 大 O 的定义

若存在常数 `c > 0` 和 `n₀`，使得：

$$
\forall n\ge n_0,\quad 0\le f(n)\le cg(n)
$$

则：

$$
f(n)=O(g(n))
$$

例如：

$$
3n^2+2n+1=O(n^2)
$$

同时也成立：

$$
3n^2+2n+1=O(n^3)
$$

原因是 O 只表示上界，不要求是最紧的上界。

### 3.3 大 Ω 的定义

存在常数 `c > 0` 和 `n₀`，使得：

$$
\forall n\ge n_0,\quad f(n)\ge cg(n)
$$

则：

$$
f(n)=\Omega(g(n))
$$

### 3.4 大 Θ 的定义

$$
\boxed{
f(n)=\Theta(g(n))
\iff
f(n)=O(g(n))\land f(n)=\Omega(g(n))
}
$$

例如：

$$
3n^2+2n+1=\Theta(n^2)
$$

但：

$$
3n^2+2n+1\ne\Theta(n^3)
$$

### 3.5 小 o 与小 ω

对于最终为正的函数，在相应极限存在时：

$$
f(n)=o(g(n))
\iff
\lim_{n\to\infty}\frac{f(n)}{g(n)}=0
$$

$$
f(n)=\omega(g(n))
\iff
\lim_{n\to\infty}\frac{f(n)}{g(n)}=\infty
$$

例如：

$$
n=o(n^2)
$$

$$
n^2=\omega(n)
$$

### 3.6 渐近分析注意事项

对于：

$$
T(n)=3n^2+4n\log n+7
$$

令：

$$
T'(n)=3n^2
$$

正确的渐近关系是：

$$
\lim_{n\to\infty}\frac{T(n)}{T'(n)}=1
$$

因此：

$$
T(n)\sim T'(n)
$$

**不能写成 $T(n)-T'(n)\to0$**，因为这里的差值实际上趋于无穷。

这是课件中的一处数学表述笔误。

## 四、典型算法复杂度

### 4.1 寻找数组最大值

```python
def find_max(a):
    ans = a[0]

    for x in a[1:]:
        if x > ans:
            ans = x

    return ans
```

核心操作：比较 `n-1` 次。

时间复杂度：

$$
T(n)=\Theta(n)
$$

额外空间：算法逻辑只需要一个变量，为 `O(1)`；这里 Python 切片 `a[1:]` 实际会额外创建数组。若要求严格的 `O(1)` 额外空间，应改为按下标遍历。

### 4.2 选择排序

```python
def selection_sort(a):
    n = len(a)

    for i in range(n - 1):
        min_idx = i

        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j

        a[i], a[min_idx] = a[min_idx], a[i]
```

比较次数：

$$
(n-1)+(n-2)+\cdots+1
$$

$$
=\frac{n(n-1)}2
$$

因此：

$$
\boxed{T(n)=\Theta(n^2)}
$$

额外空间：

$$
S(n)=O(1)
$$

注意：普通选择排序即使数组已经有序，比较次数仍然是 `n(n-1)/2`。

### 4.3 两个矩阵相加

输入两个 `m × n` 矩阵：

$$
C[i][j]=A[i][j]+B[i][j]
$$

需要遍历 `m × n` 个元素。

时间复杂度：

$$
T(m,n)=\Theta(mn)
$$

空间复杂度：

- 新建结果矩阵：`O(mn)`。
- 允许原地覆盖其中一个矩阵：额外空间 `O(1)`。

## 五、课件习题

### 题 1：为什么 swap 无法交换实际参数？

**难度：简单**

原始程序：

```cpp
void swap(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
}
```

问题：这里使用值传递。

调用函数时，`x` 和 `y` 是实际参数的副本。

函数只修改了副本，不会影响调用者的变量。

正确实现：

```cpp
void swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}
```

`int&` 表示引用，形参与实参绑定，因此可以修改原变量。

复杂度：

- 时间：`O(1)`。
- 空间：`O(1)`。

### 题 2：判断数组是否已经排序

**难度：简单**

题目默认判断非降序排列。

思路：检查全部相邻元素。

只要存在：

$$
a[i]<a[i-1]
$$

就说明数组无序。

```python
def is_sorted(a):
    for i in range(1, len(a)):
        if a[i] < a[i - 1]:
            return False

    return True
```

时间复杂度：最坏 `O(n)`。

空间复杂度：`O(1)`。

注意：允许相等元素，因此使用 `<` 判断逆序，而不是 `<=`。

### 题 3：求最大值、最小值、平均值

**难度：简单**

一次遍历同时维护：

- 最大值 `max_val`
- 最小值 `min_val`
- 总和 `total`

```python
def statistics(a):
    if not a:
        raise ValueError("数组不能为空")

    max_val = min_val = a[0]
    total = 0

    for x in a:
        max_val = max(max_val, x)
        min_val = min(min_val, x)
        total += x

    return max_val, min_val, total / len(a)
```

时间复杂度：

$$
O(n)
$$

额外空间：

$$
O(1)
$$

平均值公式：

$$
\overline{x}=\frac{\sum_{i=1}^{n}a_i}{n}
$$

### 题 4：单链表尾部插入节点

**难度：基础**

思路：

1. 创建新节点，`next` 初始化为空。
2. 如果链表为空，直接让头指针指向新节点。
3. 否则遍历到最后一个节点。
4. 让末尾节点的 `next` 指向新节点。

C++ 实现：

```cpp
struct Node {
    int data;
    Node* next;
};

void insertAtEnd(Node*& head, int value) {
    Node* node = new Node{value, nullptr};

    if (head == nullptr) {
        head = node;
        return;
    }

    Node* cur = head;

    while (cur->next != nullptr) {
        cur = cur->next;
    }

    cur->next = node;
}
```

这里 `Node*& head` 是指针的引用，可以修改头指针本身。

复杂度：

| 情况         | 时间 |
| ------------ | ---- |
| 空链表       | O(1) |
| 普通链表尾插 | O(n) |
| 维护尾指针   | O(1) |

关键：**是否维护尾指针，会直接影响尾插复杂度。**

### 题 5：实现栈

**难度：基础**

栈遵循 LIFO：后进先出。

使用数组实现时，维护 `top` 指针。

初始化：

```text
top = -1
```

三个基本操作：

**push(x)：**

```text
检查是否栈满
top = top + 1
stack[top] = x
```

**pop()：**

```text
检查是否栈空
value = stack[top]
top = top - 1
返回 value
```

**top()：**

```text
检查是否栈空
返回 stack[top]
```

复杂度：

| 操作 | 时间 |
| ---- | ---- |
| push | O(1) |
| pop  | O(1) |
| top  | O(1) |

数组容量为 `n` 时，存储空间为 `O(n)`。

### 题 6：实现循环队列

**难度：基础，注意边界**

队列遵循 FIFO：先进先出。

循环队列利用取模实现数组空间复用：

$$
next(i)=(i+1)\bmod capacity
$$

一种常见实现约定：

- `front` 指向队首元素。
- `rear` 指向下一个可以插入的位置。
- 初始化 `front = rear = 0`。
- 牺牲一个数组位置区分队满和队空。

队空：

$$
front=rear
$$

队满：

$$
(rear+1)\bmod capacity=front
$$

入队：

```text
检查队列是否已满

queue[rear] = value

rear = (rear + 1) % capacity
```

出队：

```text
检查队列是否为空

value = queue[front]

front = (front + 1) % capacity

返回 value
```

注意：课件采用了另一种约定，以 `front = rear = -1` 表示空队列，最后一个元素出队后重新设置为 `-1`。两种方案都可以，但不能混用判空、判满条件。

时间复杂度：

- 入队 `O(1)`。
- 出队 `O(1)`。
- 查看队首 `O(1)`。

### 题 7：递归函数调用次数

**难度：中等，重点掌握**

题目：

```cpp
int x(int n) {
    if (n <= 3)
        return 1;
    else
        return x(n - 2) + x(n - 4) + 1;
}
```

求执行 `x(8)` 时，函数总共调用了多少次。

#### 7.1 分析递归结构

对于 `n <= 3`，直接返回，不再产生新的递归调用。

对于 `n > 3`：

```text
x(n)
├── x(n-2)
└── x(n-4)
```

每次调用包含：

1. 当前函数本身的一次调用。
2. `x(n-2)` 产生的调用。
3. `x(n-4)` 产生的调用。

#### 7.2 建立调用次数递推式

令 `C(n)` 为执行 `x(n)` 产生的总函数调用次数。

则：

$$
C(n)=
\begin{cases}
1,&n\le3\\
1+C(n-2)+C(n-4),&n>3
\end{cases}
$$

注意：前面的 `1` 表示当前函数的一次调用。

#### 7.3 逐步计算

首先：

$$
C(0)=C(2)=1
$$

然后：

$$
C(4)=1+C(2)+C(0)
$$

$$
=1+1+1=3
$$

继续：

$$
C(6)=1+C(4)+C(2)
$$

$$
=1+3+1=5
$$

最后：

$$
C(8)=1+C(6)+C(4)
$$

$$
=1+5+3
$$

$$
\boxed{C(8)=9}
$$

#### 7.4 易错点

**第一：不要漏掉当前调用。**

即使递归到了终止条件，也执行了一次函数。

**第二：重复出现的递归调用必须重复计数。**

例如不同递归分支都执行了 `x(4)`，不能因为参数相同就只计数一次。

**第三：区分返回值和函数调用次数。**

一般递归程序中，这两者不是同一个概念。

但是本题恰好满足：

```cpp
return x(n-2) + x(n-4) + 1;
```

且终止时返回 `1`。

因此本题的返回值递推式与调用次数递推式相同，两者都等于 `9`。

如果把返回表达式中的 `+1` 修改为 `+2`，返回值就可能与调用次数不同。

### 题 8：数组中只出现一次的两个数字

**难度：中等偏上，重点掌握**

题目：

一个整数数组中，恰好有两个数字只出现一次，其余数字均出现两次。

要求找出这两个数字，并按照从小到大返回。

例如：

```text
输入：[1, 4, 1, 6]
输出：[4, 6]
```

#### 8.1 普通解法

使用哈希表统计频率。

```python
from collections import Counter

def find_once(nums):
    count = Counter(nums)

    return sorted(
        x for x, freq in count.items()
        if freq == 1
    )
```

时间复杂度：平均 `O(n)`，结果只有两个元素，排序开销为常数。

空间复杂度：`O(n)`。

但本题可以使用异或，将额外空间降低至 `O(1)`。

#### 8.2 异或的基本性质

异或满足：

$$
a\oplus a=0
$$

$$
a\oplus0=a
$$

以及交换律、结合律：

$$
a\oplus b=b\oplus a
$$

$$
(a\oplus b)\oplus c=a\oplus(b\oplus c)
$$

例如：

```text
4 = 100
6 = 110

4 ^ 6 = 010 = 2
```

两个相同数字异或，结果一定为零。

#### 8.3 第一步：全部元素异或

设两个只出现一次的数字为 `a`、`b`。

对数组全部元素异或：

$$
xor=a\oplus b
$$

因为其他数字都出现两次，全部抵消。

例如：

```text
[1, 4, 1, 6]
```

则：

$$
1\oplus4\oplus1\oplus6=4\oplus6=2
$$

得到：

```text
xor = 2
```

#### 8.4 第二步：找到一个不同的二进制位

由于：

$$
a\ne b
$$

因此：

$$
a\oplus b\ne0
$$

说明 `a` 和 `b` 至少存在一个不同的二进制位。

取异或结果中最低位的 `1`：

```python
mask = xor & -xor
```

例如：

```text
xor  = 010
mask = 010
```

该位说明：

- `a` 在这一位可能为 0。
- `b` 在这一位必然为 1。

或者相反。

所以可以用这一位将两个目标数字分开。

#### 8.5 第三步：按该位分组

遍历所有数字：

```python
if num & mask:
    # 第一组
else:
    # 第二组
```

为什么这样分组一定正确？

**原因一：两个目标数字一定进入不同组。**

因为它们在选定的二进制位上不同。

**原因二：出现两次的相同数字一定进入同一组。**

因为相同数字的每一位完全相同。

因此，每个分组内部的重复数字都可以通过异或抵消。

最终：

- 第一组异或得到 `a`。
- 第二组异或得到 `b`。

#### 8.6 完整实现

```python
def find_nums_appear_once(nums):
    xor = 0

    # 第一步：全部异或
    for num in nums:
        xor ^= num

    # 第二步：寻找最低位的 1
    mask = xor & -xor

    # 第三步：按该位分组异或
    a = 0
    b = 0

    for num in nums:
        if num & mask:
            a ^= num
        else:
            b ^= num

    return [min(a, b), max(a, b)]
```

复杂度：

$$
\boxed{T(n)=O(n)}
$$

$$
\boxed{S(n)=O(1)}
$$

#### 8.7 本题的核心思想

这道题不是简单地利用异或消除重复数字。

真正的关键是：

**利用两个目标数字必定存在的不同二进制位，把原问题分解成两个“只有一个数字出现一次”的子问题。**

最后再分别使用异或求解。

这也是一种通过问题变换降低求解难度的思路。

### 6.3 考试易错点

- **大 O 不等于精确复杂度**：它只是渐近上界。
- **嵌套循环不能无条件直接相乘**：应分析真实执行次数。
- **递归调用次数需要包含终止条件对应的函数调用**。
- **相同参数的递归调用，如果没有记忆化，仍可能重复执行**。
- **栈和队列必须处理空与满的边界**。
- **循环队列不同实现方案的判空、判满条件不能混用**。
- **异或只能抵消相同数字，分组才能分离两个不同的目标数字**。
